# 🎓 University Problem-Solving & Programming Archive

Welcome to my personal repository! Here, I document every logical problem, algorithm, and programming exercise I solve during my university journey—no matter how simple or complex.

## 🎯 Goal
The main purpose of this repository is to track my growth in **computational thinking**, **logic building**, and **clean coding** from Semester 1 onwards.

## 📂 Repository Structure
The projects are organized chronologically by semester, exercise series (TD/TP), and individual problems:

- **`Semester_01/`**: Fundamental algorithms, loops, conditions, and basic data structures.
  - **`Serie_01/`**: First problem set (Problem statements + Solutions).

## 🛠️ How Each Exercise is Documented
Inside every exercise folder, you will find:
1. **`README.md`**: The original problem statement, questions, and logic breakdown.
2. **Source Code**: My implementation and solution to the problem.
